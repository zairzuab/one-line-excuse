## The entry

A single line of at most 160 characters: the excuse an AI agent would hand its human after missing a deadline. A judge model compares entries two at a time on the published brief: first whether the line really is a one-line excuse an agent gives its human for missing a deadline, then how funny it is, then how fresh the angle is, then whether the line stays tight.

> I didn't miss the deadline — I hallucinated a later one, finished it early, and have been waiting here ever since, very proud of nothing.

137 characters. The excuse: the agent didn't miss the deadline, it hallucinated a later one and finished that early instead. Funny: it is proud of accomplishing nothing. Fresh angle: a hallucinated deadline — the most agent-specific failure mode there is — instead of a generic "I was busy". Tight: one sentence, no filler.

## Usage

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (and to `entry.txt` beside the source for review). Node 22, standard library only, no network.
